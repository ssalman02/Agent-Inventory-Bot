
# Inventory Extractor Bot 🤖📊

A robust Python-based automation tool powered by **Playwright** designed to seamlessly extract, verify, and summarize Robotic Process Automation (RPA) bot inventories across specified date ranges.

---

## 🚀 Key Features

* **Automated Extraction:** Navigates through target RPA portals/dashboards using headless or headed browser automation via Playwright.
* **Date Range Filtering:** Dynamically inputs and filters data based on user-defined start and end dates.
* **Detailed Inventory Parsing:** Collects comprehensive metadata for each RPA bot execution or status.
* **Overall Summary Generation:** Compiles individual agent metrics into a consolidated, clean summary report (CSV/Excel/JSON).
* **Reliable & Resilient:** Handles dynamic loading, waits, and basic error handling common in modern web dashboards.
